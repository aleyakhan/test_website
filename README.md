# My Creative Corner

A simple personal website for the Stepstone 2 assignment.

## Customize it

Open `index.html` and replace:

- `[Your name]` with your name.
- The biography paragraphs in the **About me** section with your own short biography.
- The painting image URL, description, caption, and short explanation with your favorite painting.

## Publish with GitHub Pages

1. Commit and push these files to your GitHub repository.
2. On GitHub, open **Settings**, then **Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for the deployment, then open the site link shown in the repository’s **Deployments** section.
